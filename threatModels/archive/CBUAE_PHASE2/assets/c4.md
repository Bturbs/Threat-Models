# C4 Diagrams

The main C4 Strictirizr  diagram is `workspace.dsl` file

## Commands (from asset directory):

View the diagrams online on port 8080 (preferred)

- `docker run -it --rm -p 8080:8080 -v .:/usr/local/structurizr structurizr/lite`


OR plant uml export (not full features)

- `structurizr-cli export -w workspace.dsl -f plantuml`
